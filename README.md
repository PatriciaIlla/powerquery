# Dashboard de Lucro e Vendas - Power BI

Projeto do desafio da DIO (Formação Power BI Analyst).

## Sobre
Relatório em Power BI com a base Financial Sample, analisando vendas e lucro por páis, segmento e período.

## Páginas
- Página 1 (Sales Report)
- Página 2 (Report de Lucro Detalhado)
- Relatório de Vendas por País

## Ferramenta
Power BI Desktop
